# Roulette Simulator

Simulateur de roulette : on lance la roue, on suit la bille, on joue une mise.
Interface en Next.js, déployée sur Vercel.

## Fonctionnalités

- Roue animée et gestion des mises
- Historique des tours
- Interface responsive

## Stack

- **Next.js** (App Router)
- **React**
- **TypeScript**
- **Tailwind CSS**

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
